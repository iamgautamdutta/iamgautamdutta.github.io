Personal portfolio website of **Gautam Dutta**, an AI & Data Science student and full-stack developer from New Delhi, India.

**Live site:** https://iamgautamdutta.github.io

---

## About

This site shows who I am, what I build, and where I have worked and studied. It includes my skills, featured projects, internships, certificates, and a downloadable resume.

## Sections

- **Hero:** intro with a typing animation
- **About:** short bio and key stats
- **Skills:** languages, frameworks, cloud and tools, shown in a terminal-style card
- **Work:** featured projects
- **Journey:** experience and education timeline, with internship documents
- **Certifications & Milestones:** scrollable certificate gallery
- **Resume:** view or download my CV
- **Contact:** email, LinkedIn, GitHub and a contact form

## Run Locally

No installation is needed.

1. Download or clone this repo:
   ```
   git clone https://github.com/iamgautamdutta/iamgautamdutta.github.io.git
   ```
2. Open `index.html` in your browser.

## Deploy

The site is deployed with GitHub Pages.

1. Push the files to the `main` branch.
2. Go to **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then choose **main** and **/ (root)**.
4. The site updates a minute or two after each commit.
